# Keybindings Reference

Complete list of all keyboard shortcuts in LazyFire.

## Global

| Key | Action |
|-----|--------|
| `q` | Quit |
| `?` | Show help |
| `Esc` | Close popup / cancel |
| `r` | Refresh current panel |

## Navigation

| Key | Action |
|-----|--------|
| `Tab` | Next panel |
| `Shift+Tab` | Previous panel |
| `h` | Move left |
| `l` | Move right |
| `1` | Go to Projects |
| `2` | Go to Collections |
| `3` | Go to Tree |
| `4` | Go to Details |

## List Movement

| Key | Action |
|-----|--------|
| `j` / `↓` | Move down |
| `k` / `↑` | Move up |
| `gg` | Go to top |
| `G` | Go to bottom |
| `Ctrl+d` | Page down |
| `Ctrl+u` | Page up |

## Selection

| Key | Action |
|-----|--------|
| `Space` | Select / expand item |
| `Enter` | Open / confirm |
| `v` | Toggle select mode |
| `V` | Select all visible |

## Tab Switching

### Collections Panel

| Key | Action |
|-----|--------|
| `[` | Collections tab |
| `]` | Functions tab |

### Details Panel

| Key | Action |
|-----|--------|
| `[` | Details tab |
| `]` | Logs tab |

## Filtering

| Key | Action |
|-----|--------|
| `/` | Start filter |
| `Enter` | Apply filter |
| `Esc` | Cancel / clear filter |
| `Ctrl+u` | Clear filter text |

## Tree Panel

| Key | Action |
|-----|--------|
| `Space` | Expand / collapse |
| `h` | Go to parent |
| `l` | Enter child |
| `Backspace` | Go back |

## Details Panel

| Key | Action |
|-----|--------|
| `j` / `k` | Scroll content |
| `Ctrl+d` / `Ctrl+u` | Page scroll |

## Select Mode

| Key | Action |
|-----|--------|
| `j` / `k` | Move cursor |
| `Space` | Toggle selection |
| `V` | Select all |
| `Esc` | Exit select mode |
