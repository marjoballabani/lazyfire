# Keybindings Reference

Complete list of all keyboard shortcuts in LazyFire.

## Global

| Key | Action |
|-----|--------|
| `q` | Quit |
| `?` | Show help |
| `Esc` | Close popup / go back |
| `r` | Refresh current panel |
| `F` | Open query builder |

## Navigation

| Key | Action |
|-----|--------|
| `Tab` | Next panel |
| `Shift+Tab` | Previous panel |
| `h` / `l` | Move left / right between panels |
| `1` | Go to Projects |
| `2` | Go to Collections |
| `3` | Go to Tree |
| `4` | Go to Details |

## List Movement

| Key | Action |
|-----|--------|
| `j` / `Down` | Move down |
| `k` / `Up` | Move up |
| `gg` | Go to top |
| `G` | Go to bottom |
| `Ctrl+d` | Page down |
| `Ctrl+u` | Page up |

## Selection

| Key | Action |
|-----|--------|
| `Space` | Select / expand item |
| `Enter` | Open / confirm |
| `v` | Toggle select mode |
| `V` | Select all visible |

## Tab Switching

### Collections Panel

| Key | Action |
|-----|--------|
| `[` | Collections tab |
| `]` | Functions tab |

### Details Panel

| Key | Action |
|-----|--------|
| `[` | Details tab |
| `]` | Logs tab |

## Filtering

| Key | Action |
|-----|--------|
| `/` | Start filter |
| `Enter` | Apply filter |
| `Esc` | Cancel / clear filter |
| `Ctrl+u` | Clear filter text |

Type any letter to start filtering in projects, collections, and tree panels.

## Projects Panel

| Key | Action |
|-----|--------|
| `Space` | Select project |
| `Enter` | Fetch project details |
| `S` | Scan collections health |

## Collections Panel

| Key | Action |
|-----|--------|
| `Space` | Select collection |

## Tree Panel

| Key | Action |
|-----|--------|
| `Space` | Expand / collapse node |
| `h` | Go to parent |
| `l` | Enter child |
| `Backspace` | Go back |
| `s` | Save document as JSON |
| `c` | Copy document JSON |

## Details Panel

| Key | Action |
|-----|--------|
| `j` / `k` | Scroll content |
| `Ctrl+d` / `Ctrl+u` | Page scroll |
| `s` | Save content (JSON or scan report as Markdown) |
| `c` | Copy content (JSON or scan report as Markdown) |

## Select Mode

| Key | Action |
|-----|--------|
| `j` / `k` | Move cursor |
| `Space` | Toggle selection |
| `V` | Select all |
| `Esc` | Exit select mode |

## Query Builder

| Key | Action |
|-----|--------|
| `Tab` | Next field |
| `Shift+Tab` | Previous field |
| `Enter` | Execute query |
| `Esc` | Close query builder |

## Confirm Dialog

| Key | Action |
|-----|--------|
| `Enter` | Confirm |
| `Esc` | Cancel |
